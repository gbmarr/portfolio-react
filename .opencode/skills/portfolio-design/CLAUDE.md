# portfolio-design Design System

This project uses the **portfolio-design** design system (Tailwind CSS v4, tokens in `src/index.css` `@theme`).

## How to use

Read `SKILL.md` in this directory for the design system reference before writing any UI code.

Key files:
- `SKILL.md` — master design reference (read this first: tokens, typography, spacing, rules)
- `references/DESIGN.md` — extended component pattern inventory (70 real patterns with Tailwind classes)

When building any UI, always read `SKILL.md` first and match colors, fonts, spacing, and motion exactly.
